# Banking Program

A simple console-based banking application built with Python.

## Features

* View account balance
* Deposit funds
* Withdraw funds
* Validate transaction amounts
* Prevent withdrawals exceeding the available balance

## Technologies

* Python
* Functions
* Conditional Logic
* Loops
* User Input & Validation

## How to Run

1. Make sure Python is installed.
2. Clone or download the repository.
3. Run:

```bash
python banking_program.py
```

## Purpose

This project was created to practice fundamental Python programming concepts, including functions, loops, conditional logic, input validation, and basic application state management.
